## 1. 选题背景

角动量守恒是大学物理力学部分的核心规律之一，也是学生最容易「背得出公式、说不清条件」的知识点。传统课堂存在三个难点：

1. **条件抽象**：学生常把「合外力为零」误当成守恒条件，忽略真正条件是「合外力矩为零」；也容易把角动量守恒说成「角速度守恒」。
2. **过程不可见**：真实转台实验受器材、摩擦、安全与课时限制，难以让学生反复改变转动惯量并同时观察 \(I\)、\(\omega\)、\(L\)、\(E_k\) 四个量。
3. **能量与角动量混淆**：收臂时角动量守恒而转动动能增加，能量来自人体做功；子弹嵌入杆时角动量守恒而机械能大量损失。这两个反直觉现象若只靠讲解，很难形成稳定理解。

现有仿真作品大多以「播放一段动画」为主：学生看完就结束，缺少预测、测量、纠错与评估。本项目希望把实验做成一个可反复试错的学习闭环，并让 AI 真正进入实验流程，而不是在旁边放一个聊天框。

**一句话目标：让学生在 5 分钟内经历一次「预测—操作—测量—解释—反思」，并得到基于自己数据的诊断。**

## 2. 仿真目标

### 2.1 知识目标

- 理解角动量 \(L=I\omega\) 与转动惯量 \(I=I_0+2mr^2\) 的物理意义；
- 掌握角动量守恒的条件：对选定参考点合外力矩为零；
- 能区分「角动量守恒」与「角速度守恒」「机械能守恒」；
- 能用 \(mvd=I\omega\) 分析子弹击杆这类绕支点的碰撞；
- 理解转动动能 \(E_k=L^2/(2I)\) 与内力做功的关系。

- **科学探究**：先预测后验证，记录多组数据，用偏差判断结论可靠性；

- **证据意识**：用自己记录的数据而非教材结论支撑判断；
- **反思能力**：写出一段包含条件、过程、能量来源的完整因果链。

### 3.3 物理内核：为什么用 L 做状态量

若以角速度 \(\omega\) 为状态量，学生在拖动半径的每一帧都需要重新计算 \(I\)，再用 \(L=I\omega\) 反推，容易积累数值误差，甚至出现「改半径时 L 漂移」的假象。

本项目把 **角动量 L 作为唯一的转动状态量**：

- 改变半径：只改 \(I\)，\(\omega=L/I\) 自动变化，\(L\) 严格不变；
- 开启摩擦：摩擦冲量矩直接作用于 \(L\)，对应 \(\mathrm{d}L/\mathrm{d}t=\tau_{\text{ext}}\)；
- 转动动能：始终由 \(E_k=L^2/(2I)\) 导出，不会与 \(L\) 的守恒性冲突。

这使「守恒」成为模型的天然性质，而不是靠每帧修补出来的视觉效果。

### 3.4 渲染与性能

- 单页最多同时只有一个 Canvas 动画在跑；切换视图时只绘制当前视图。
- 平台背景、桌面网格等静态图层预渲染到离屏 Canvas，每帧用 `drawImage` 合成。
- 人物、哑铃、轨迹、粒子使用轻量矢量绘制；去掉开销大的逐帧 `ctx.filter` 与 `shadowBlur`。
- 设备像素比上限为 2，避免高分屏 3x 渲染造成 GPU 峰值。
- 图表以约 6 fps 重绘，物理与场景保持 60 fps。
- 首屏文本资源约 **335 KB**（gzip ≈ **91 KB**），无外部字体、CDN 与图片阻塞。

## 4. AI 赋能实现思路

### 4.1 设计原则：AI 嵌入实验流程，而不是外挂聊天

本项目把 AI 放在四个位置：

1. **实验前**：提示先预测，给出可检验的思考框架；
2. **实验中**：读取实时 \(I,\omega,L,E_k,r\)，解释正在发生的现象；
3. **实验后**：读取全部测量数据，判断偏差来源，给出下一步；
4. **评估中**：按概念量规给自由文本评分，自适应选题并更新掌握度。

它不是一个只能闲聊的机器人：每次回答都可以调用物理计算、读取状态、引用学生数据，并且能被任务/测评/报告验证。

### 4.2 四层 AI 教学引擎

| 层 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 感知 | 当前视图、L/I/ω/Ek、数据表、任务、测评、反思 | 构建上下文快照 `buildContext()` | 结构化状态 |
| 诊断 | 学生问题 / 预测 / 自由文本 | 意图匹配、数值计算、迷思规则、量规匹配 | 诊断结论与证据 |
| 决策 | 掌握度、任务进度、最近对话 | 选择下一步：解释 / 提示 / 出题 / 报告 | 苏格拉底式行动 |
| 生成 | 结论与数据 | 模板 + 数值 + 可选的云端 LLM | 带具体数值的回答 |

### 4.3 功能拆解

#### （1）情境化答疑

回答不是固定文案，而是代入当前数值。例如问「为什么收臂后角速度会变大」，本地引擎会：

1. 读取当前 \(I,\omega,L,E_k\)；
2. 计算目标半径 \(r=0.30\) m 下的 \(I'=I_0+2mr'^2\)；
3. 由 \(L\) 守恒得到 \(\omega'=L/I'\)，并与当前值比较倍数；
4. 用 \(E_k'=L^2/(2I')\) 说明动能变化与做功来源；
5. 给出一句可执行的下一步：「把 r 拖到 0.30 m，看看 HUD 是否吻合」。

#### （2）迷思概念诊断

本地规则库覆盖 6 类高频迷思：

| 学生说法 | AI 诊断 | 教学处理 |
| --- | --- | --- |
| 「角速度守恒」 | 守恒的是 L，不是 ω | 用 \(L=I\omega\) 说明 I 变小时 ω 必须变 |
| 「能量也守恒」 | 本实验机械能不守恒 | 区分角动量与能量；说明内力做功 |
| 「半径越大转得越快」 | 方向反了 | 用 \(\omega=L/I\) 与收臂现象对照 |
| 「合外力为零就守恒」 | 忽略力矩条件 | 引入力偶反例，强调「合外力矩」 |
| 「线动量守恒」 | 支点有冲力 | 解释支点冲力过支点、力矩为零 |
| 「离心力」 | 惯性系中不存在 | 说明向心力、惯性趋势与做功 |

每条规则返回「纠正 + 解释 + 可检验操作」，而不是简单说「错了」。

#### （3）自适应测评

- 题库由工厂函数生成，数值题随机参数，避免背答案；
- 6 个概念：定义、守恒条件、定量计算、能量、碰撞、实验与误差；
- 选题：优先掌握度最低的概念，再匹配难度（< 0.45 → 基础，< 0.72 → 应用，否则综合）；
- 掌握度更新：答对 \(m \leftarrow m+0.3(1-m)\)，答错 \(m \leftarrow m-0.2m\)；
- 每个错误选项都有独立 `why`，判分时返回针对性解释；
- 数值题按相对容差判分，并根据误差量级给出「公式/单位/数量级」提示。

#### （4）量规评分

任务 3、任务 5 与学习反思采用「概念覆盖度量规」，而不是模糊的聊天评价：

| 评价项 | 权重示例 | 判定方式 |
| --- | --- | --- |
| 收臂时人对配重做正功 | 2 | 动词 + 施力主体同现 |
| I 减小 | 1.5 | 关键词 / 符号 |
| ω 增大 | 1.5 | 关键词 / 符号 |
| L 守恒（外力矩为零） | 1.5 | 角动量 + 守恒/不变 |
| 篇幅与数值证据 | 修正项 | 过短降权；含数值小幅加分 |

评分结果同时返回「已覆盖 / 仍缺少」的具体条目，学生知道下一步补什么。

#### （5）数据驱动报告

报告中的每一句话都来自学生的真实数据：

- 数据组数、\(L\) 平均值、最大相对偏差、半径范围、摩擦状态；
- 任务分、测评分、反思分与总分拆解；
- 五维能力雷达：概念理解、定量计算、实验操作、数据分析、科学解释；
- 根据薄弱概念生成下一步按钮（去实验台 / 去碰撞 / 去测评 / 让 AI 讲）。

#### （6）语音与可选云端 LLM

- **语音输入**：Web Speech API 中文识别，识别后自动发送；不支持时隐藏麦克风按钮；
- **语音朗读**：`speechSynthesis` 播报 AI 回复，可随时关闭；
- **可选云端 LLM**：在 AI 设置中填写兼容 OpenAI Chat Completions 的接口地址、模型名与 Key。请求会注入当前实验状态与系统提示词；若网络、跨域或超时失败，自动回退本地引擎并说明原因。Key 只保存在 `sessionStorage`，刷新页面即失效。

### 4.4 为什么这不是「简单聊天机器人」

| 普通聊天机器人 | 本项目的 AI |
| --- | --- |
| 只根据文字回复 | 读取实时物理量、数据表、任务进度 |
| 可能编造数值 | 所有数值由本地物理模型计算 |
| 无法验证 | 回答可被实验台 / 任务 / 报告检验 |
| 答题直接给答案 | 先提示，必要时才给解法 |
| 无学习记录 | 掌握度、任务、反思进入报告 |
| 断网不可用 | 本地引擎完整可用，云端仅为增强 |

### 4.5 局限与人工兜底

- 本地引擎是规则 + 模板系统，不具备开放域推理能力；复杂追问会退回「守恒框架 + 上下文」的通用回答；
- 量规评分基于关键词/概念覆盖，不能完全替代教师对论证质量的判断；
- 云端 LLM 可能因跨域或配额失败，必须无感回退；
- 所有 AI 输出都标注来源（本地 / 云端 / 主动提示），并提示「以教材为准」。

### 6.3 三分钟快速开始

1. 打开「实验台」，平台默认已开始旋转；
2. 拖动左右哑铃（或「配重半径」滑杆）从 0.60 m 收到 0.30 m；
3. 观察角速度变大、角动量 L 基本不变、动能增加；
4. 在不同半径点三次「记录数据」；
5. 打开任务 1，点「检查我的数据」；
6. 点右上角「AI 助教」，问「用我的数据解释一下」。

### 6.4 实验台任务

**任务 1 · 观察守恒（12 分）**

- 同一次转动中记录 ≥ 3 组不同半径数据；
- 半径跨度 ≥ 0.25 m；
- L 最大相对偏差 ≤ 2%；
- 建议关闭轴承摩擦；点「检查我的数据」自动评分。

**任务 2 · 定量预测（10 分）**

- 保持转动，预测把半径收到 0.30 m 后的 ω；
- 用 \(I'=I_0+2mr'^2\)，再由 \(L=I\omega\) 求 \(\omega'=L/I'\)；
- 输入预测值提交；20% 内得分，越接近越高；
- 到 0.30 m 后可点「验证实际值」对照。

**任务 3 · 能量解释（8 分）**

- 用 30 字以上解释：为什么 L 不变而 \(E_k\) 增大？能量来自哪里？
- 点「交给 AI 评分」；AI 按「做功 / I 减小 / ω 增大 / L 守恒」四项量规评分；
- 评分 ≥ 60 即完成，反馈会指出遗漏项。

### 6.5 碰撞实验

**任务 4 · 碰撞预测（12 分）**

- 调节子弹质量、速度、击点距离 d；
- 用 \(mvd=I\omega\)、\(I=ML^2/12+md^2\) 估算碰后 ω，填入预测框并提交；
- 10% 内通过；点「发射子弹」观看慢放动画，对比实测值。

**任务 5 · 碰撞解释（8 分）**

- 解释：为什么角动量守恒、线动量和机械能却不守恒？损失的能量去哪了？
- 点「提交 AI 评分」，量规覆盖「角动量守恒 / 支点冲力 / 线动量不守恒 / 完全非弹性 / 内能热」等。

### 6.6 智能测评

1. 进入「智能测评」，点「开始智能测评」；
2. 共 8 题，AI 根据你的掌握度动态选择概念与难度；
3. 选择题点击选项后提交；数值题输入数字（允许 3%–5% 容差）；
4. 每题提交后立即显示纠错与解析，点「下一题」继续；
5. 完成后显示得分、各概念正确率、薄弱点，并自动更新雷达与报告。

### 6.7 学习报告

- 查看总分、等级、分项得分、能力雷达、AI 诊断；
- 写学习反思（80 字以上）并点「AI 评分」，计入 20 分；
- 「导出档案」下载 JSON；「打印报告」生成适合提交的打印版；
- 姓名可选，仅保存在本机。

### 6.8 AI 助教

- 点击右上角「AI 助教」打开；
- 可直接提问，或点快捷问题（怎么玩 / 为什么变快 / 下一步 / 考考我 / 分析数据）；
- 出题后直接回复数值，AI 会判题；回复「提示」「答案」获得帮助；
- 麦克风按钮支持中文语音输入（浏览器支持时）；

- 齿轮按钮打开设置：语音、音效、可选云端大模型。

### 6.9 移动端提示

- 建议竖屏使用；实验台可点右上角全屏按钮；
- 拖动哑铃时请避开页面滚动区域（画布已禁用触摸滚动）；

## 9. 设计思考与迭代记录

### 9.1 关键取舍

1. **不用 3D 引擎**：Three.js 能带来更真实的 3D，但首屏体积、移动端 GPU 与加载时间都会上升。最终选择 Canvas 2D + 透视投影，用光影、轨迹与矢量标注表达「转动」，把预算留给物理与 AI。
2. **不做纯聊天**：聊天框很容易变成「万能但无用」的装饰。项目把 AI 的每次回答绑定到可计算的物理量和可验证的任务上，并让评分、报告引用同一份状态。
3. **不追求「全自动」**：AI 可以诊断和提示，但关键结论仍由学生操作、记录、解释；量规评分展示依据，保留教师复核空间。

### 9.2 实际发现并修复的问题

| 问题 | 发现方式 | 修复 |
| --- | --- | --- |
| Canvas 实际只有 300×150，场景被拉伸 | 自动化截图 + `canvas.width` 检查 | 每帧按 CSS 尺寸与 DPR 同步 backing store |
| 平台顺时针转，却画了向上的 L 矢量 | 右手定则复核 | 屏幕坐标 y 向下，视觉转角取负；L 向上 |
| 量规把「做的功」判为未覆盖 | 端到端评分结果异常 | 增加同义表达，保留「做功/做的功/作功」 |
| 能量条形用对数刻度，视觉上像损失 50% | 截图对比 | 改为线性刻度，碰后只剩 3.3%，与 96.7% 损失一致 |
| 人物像「棋子」，实验感不足 | 视觉走查 | 重绘为白大褂实验者，增加肩、肘、护目镜与座椅 |
| 桌面端 39 fps | CDP 帧率测量 | 预渲染静态图层、移除逐帧 blur/shadowBlur，移动端达 60 fps |

### 9.3 后续计划

- 增加更多实验（陀螺进动、开普勒第二定律、角动量矢量合成）；
- 班级模式：教师端汇总匿名学习数据（需要后端）；
- WebXR / 手机陀螺仪：让「转动」进入三维空间；
- LLM 流式输出与多轮工具调用，让云端回答也能读数据、画图；
- 更细的论证质量评分（因果链、反例、误差讨论）。

## 3. 实验台：旋转平台

### 3.1 第一次操作（约 1 分钟）

1. 平台默认在旋转；若已暂停，点「开始」。
2. 用鼠标/手指直接拖动两侧的哑铃，向内收或向外展；
   也可以拖动右侧「配重半径 r」滑杆。
3. 看 HUD 的四个数：
   - 转动惯量 I：收臂时变小；
   - 角速度 ω：收臂时变大；
   - 角动量 L：基本不变（这就是守恒）；
   - 转动动能 Eₖ：收臂时变大。
4. 点「记录数据」保存当前一组；在不同半径记录 3 组以上。

### 3.2 收臂演示

点「收臂演示」，配重会在 1.4 秒内从当前位置收到 0.25 m。
观察 ω 的上升和 L 的稳定；完成后 AI 会主动给出对比。

### 3.3 轴承摩擦

打开「轴承摩擦」后，摩擦作为外力矩作用于转台，L 会逐渐下降。
- 验证守恒时请关闭摩擦；
- 想研究误差/阻力时再打开，并观察「L 相对偏差」变红。

### 3.4 任务 1：观察守恒（12 分）

| 要求 | 说明 |
| --- | --- |
| ≥ 3 组数据 | 点「记录数据」 |
| 半径跨度 ≥ 0.25 m | 例如 0.60 → 0.45 → 0.30 |
| L 最大相对偏差 ≤ 2% | 关闭摩擦、等平台稳定再记录 |

点任务 1 面板里的「检查我的数据」，系统自动计算得分并给出未通过原因。

### 3.5 任务 2：定量预测（10 分）

1. 保持平台转动，目标半径固定为 0.30 m；
2. 用公式先算：
   \[
   I' = I_0 + 2mr'^2,\qquad \omega' = \frac{L}{I'}
   \]
   其中 \(I_0=0.6\ \mathrm{kg\cdot m^2}\)，\(m=2\ \mathrm{kg}\)，\(L\) 看 HUD；
3. 把预测值填入输入框，点「提交预测」；
4. 误差 ≤ 20% 即完成，越接近得分越高；
5. 把半径调到 0.30 m，点「验证实际值」对照。

### 3.6 任务 3：能量解释（8 分）

1. 用 30 字以上回答：为什么 L 不变，ω 和 Eₖ 却增大？能量来自哪里？
2. 点「交给 AI 评分」；
3. AI 按四个概念点评分：做功、I 减小、ω 增大、L 守恒；
4. 评分 ≥ 60 即完成；反馈会列出你遗漏的概念。

一个合格答案的因果链：
> 收臂时转轴方向合外力矩为零，所以 L 守恒；半径减小使 I 减小，由 ω=L/I 得 ω 增大；动能增加来自人拉配重向内做的功。

## 4. 碰撞实验：子弹击杆

### 4.1 参数

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 子弹质量 m | 5–50 g | 影响碰前角动量与能量 |
| 子弹速度 v | 50–500 m/s | 影响角动量与动能 |
| 击点距离 d | 0.05–0.38 m | 力臂，直接改变角动量 |
| 杆 | M=1.0 kg，L=0.80 m，中心支点 | 固定参数 |

### 4.2 任务 4：预测碰后角速度（12 分）

1. 不发射，先计算：
   \[
   L = mvd,\qquad I = \frac{ML^2}{12}+md^2,\qquad \omega=\frac{L}{I}
   \]
2. 把 ω 填入「预测」框，点「提交预测」；
3. 误差 ≤ 10% 即通过；
4. 点「发射子弹」，观察慢放动画与实测值；
5. 若偏差大，AI 会检查你是否误用了线动量守恒（支点有冲力，线动量不守恒）。

### 4.3 任务 5：解释能量去向（8 分）

用 30 字以上解释：
- 为什么角动量守恒？
- 为什么线动量不守恒？
- 机械能损失到哪里去了？

合格答案示例：
> 碰撞瞬间支点冲力对支点的力矩为零，所以绕支点角动量守恒，mvd=Iω；但支点冲力使系统线动量不守恒；子弹嵌入杆是完全非弹性碰撞，机械能损失为内能和热。

### 4.4 能量条

- 橙色：碰撞前子弹动能；
- 蓝色：碰后转动动能；
- 线性刻度：蓝色往往只剩几个百分点，直观显示「角动量守恒 ≠ 能量守恒」。

## 5. 智能测评

1. 点顶部「智能测评」→「开始智能测评」；
2. 共 8 题，覆盖 6 个概念，系统按你的掌握度选题；
3. 选择题点击一个选项，再点「提交答案」；
4. 数值题输入数字即可（允许 3%–5% 的数值误差）；
5. 提交后立即显示：
   - 是否正确；
   - 你选错时对应的误区解释；
   - 正确公式与计算过程；
6. 点「下一题」继续；完成后显示得分、各概念正确率和薄弱点；
7. 点「查看学习报告」查看雷达与总分。

> 测评不会因为你答错而「扣很多分」；它主要用于调整后续题目和报告建议。

## 6. 学习报告

### 6.1 成绩构成（100 分）

| 部分 | 分值 | 来源 |
| --- | --- | --- |
| 实验操作 | 30 | 任务 1（12）+ 任务 2（10）+ 任务 3（8） |
| 碰撞实验 | 20 | 任务 4（12）+ 任务 5（8） |
| 智能测评 | 30 | 最近一次测评得分 × 30% |
| 学习反思 | 20 | AI 对反思文本的量规评分 × 20% |

### 6.2 能力雷达

五个维度：概念理解、定量计算、实验操作、数据分析、科学解释。
雷达取值来自任务完成度、测评掌握度、数据质量与反思评分。

### 6.3 学习反思

1. 在报告页写 80 字以上；
2. 点「AI 评分」；
3. 反馈会指出「已覆盖 / 仍缺少」的概念；
4. 得分 ≥ 60 通常已具备完整因果链。

### 6.4 导出与打印

- **打印报告**：浏览器打印，自动隐藏导航与表单，只保留报告；
- **导出档案**：下载 JSON，包含任务、数据、测评、反思与 AI 诊断；
- **导出 CSV**：实验台下方，导出原始测量数据；
- 姓名可选，只保存在本机。

## 7. AI 助教

### 7.1 能做什么

- 用你当前的 I、ω、L、Eₖ 解释现象；
- 读取测量数据，判断 L 偏差与可能原因；
- 纠正「角速度守恒」「能量也守恒」「合外力为零就守恒」等迷思；
- 根据任务进度告诉你下一步；
- 随机出题并判题；
- 按量规给任务 3/5 与反思评分；
- 生成报告诊断。

### 7.2 快捷问题

- **怎么玩？** → 三步上手；
- **为什么变快？** → 用你的数据算收臂后的 ω；
- **下一步** → 按任务进度给出顺序；
- **考考我** → 随机数值题；
- **分析数据** → 读取你的数据表。

### 7.3 出题与判题

1. 输入「出题考考我」；
2. 直接回复数值（不用写单位）；
3. 回复「提示」获得公式提示；
4. 回复「答案」查看完整解法；
5. 答错一次可以重试，第二次会给出解法。

### 7.4 语音

- 麦克风：浏览器支持时，说中文问题，识别后自动发送；
- 喇叭：开关 AI 回复的语音朗读；
- 若按钮消失，说明当前浏览器不支持语音识别，请用文字输入。

### 7.5 可选云端大模型

1. 打开 AI 助教 → 齿轮 → 打开「云端大模型」；
2. 填写兼容 OpenAI Chat Completions 的接口地址、模型名与 API Key；
3. 点「保存设置」；
4. 若接口不支持浏览器跨域或超时，会自动回退本地引擎并提示原因；
5. Key 只保存在本浏览器会话，刷新页面后失效。

> 默认不联网；不填写 Key 时，所有 AI 功能均在本地完成。

## 9. 常见问题（FAQ）

**Q1：记录时提示「平台还没有转动」？**  
点「开始」，或把「初始角速度」调大；若摩擦已让平台停转，点「复位实验」。

**Q2：为什么 L 的偏差越来越大？**  
检查是否开启了「轴承摩擦」。摩擦属于外力矩，L 不再守恒；验证守恒时请关闭。

**Q3：任务 1 总是差一点？**  
- 数据是否 ≥ 3 组？
- 半径跨度是否 ≥ 0.25 m？
- 是否中途改了初始角速度（会清空旧数据）？
- 记录时平台是否稳定、摩擦是否关闭？

**Q4：任务 3 评分只有 60 多？**  
检查是否同时写了「做功」「I 减小」「ω 增大」「L 守恒」四层；AI 反馈会列出遗漏项。

**Q5：任务 4 的预测怎么算？**  
\(L=mvd\)，\(I=ML^2/12+md^2\)，\(\omega=L/I\)。注意 d 是击点到支点的距离，不是杆长。

**Q6：AI 说云端不可用？**  
检查接口地址、Key、模型名，以及该接口是否允许浏览器跨域；关闭云端后本地引擎仍完整可用。

**Q7：数据会丢失吗？**  
学习记录保存在浏览器 localStorage；清理浏览器数据会丢失。建议在报告页导出 JSON/CSV。

**Q8：如何清空所有数据？**  
实验台「清空」连点两次；或「?」→「清除本机学习数据」→再点一次确认。

**Q9：打印出来是空白？**  
请先进入「学习报告」页，再点「打印报告」；打印样式会自动隐藏其他视图。

**Q10：可以离线使用吗？**  
页面加载完成后，核心实验与本地 AI 不依赖网络；但首次打开仍需联网加载页面。未注册 Service Worker，因此不做离线缓存。
